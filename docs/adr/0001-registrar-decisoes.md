# ADR 0001 — Registrar decisões de arquitetura

- **Status**: aceito
- **Data**: 2026-11-01

## Contexto

O projeto é open source e mantido por voluntários que entram e saem. Sem registro, o motivo das
decisões se perde e elas são rediscutidas ou desfeitas por engano.

## Decisão

Decisões de arquitetura relevantes são registradas em `docs/adr/NNNN-titulo.md`, no formato
Contexto → Decisão → Consequências. ADRs aceitos não são editados: uma mudança gera um novo ADR que
marca o anterior como substituído.

## Consequências

Revisores podem pedir um ADR em PRs que mudem a arquitetura. O plano de produto continua em
`docs/PLANO.md`.
